# Hospital Management System

A Flask + Vue.js web application for managing hospital operations.

## Features
- **Roles:** Admin, Doctor, Patient.
- **Admin:** Manage doctors, patients, view stats.
- **Doctor:** View appointments, prescribe treatments.
- **Patient:** Book appointments, view history.

## Setup Instructions

1.  **Install Dependencies:**
    ```bash
    pip install -e .
    ```

2.  **Run the Application:**
    ```bash
    python app.py
    ```
    This will also create the database and the initial Admin user on the first run.

3.  **Access the App:**
    Open your browser to: `http://127.0.0.1:5000`

## Initial Login
- **Admin Username:** `admin`
- **Admin Password:** `adminpassword`
